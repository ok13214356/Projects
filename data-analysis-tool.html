About this project

This dashboard was built as a project for a statistics course. It turns a table of 2,208 Titanic passengers and crew into an interactive tool for practicing descriptive statistics, confidence intervals, hypothesis testing and regression on a real data set with a clear binary outcome (survived or died).

The data

  • One row per person: name, outcome, port of boarding, class (1st, 2nd, 3rd or crew), sex, age, fare paid, ticket number, lifeboat or recovered-body marker, and job.
  • Overall, 712 of 2,208 people survived (32.2%).
  • Missing values: 3 ages, 890 fares (almost all crew), and 957 ticket numbers (crew and some passengers). Charts that use a variable simply skip people with a missing value for it.
  • Fares are shown in pounds as recorded in the source file. Lifeboat markers such as [190] in the source mean a body was recovered, and are treated that way here.

Methods used

  • Proportions and intervals: survival rates with 95% Wilson score intervals, which behave well for small groups.
  • Chi-square test of independence: expected counts, Pearson χ², degrees of freedom, p-value (regularised incomplete gamma) and Cramér's V as the effect size.
  • Two-group comparison: difference in proportions with a Wald interval, two-proportion z-test, odds ratio and relative risk with log-scale intervals, and Fisher's exact test. Controlling for a third variable uses the Cochran–Mantel–Haenszel common odds ratio and test, which is the standard tool for spotting Simpson's paradox.
  • Numeric comparisons: Welch's t-test (Satterthwaite degrees of freedom), Mann–Whitney U with tie correction and continuity correction, and Cohen's d.
  • Logistic regression: fitted by iteratively reweighted least squares (Newton–Raphson). Standard errors come from the inverse Fisher information, with Wald z-tests, odds ratios, McFadden's pseudo-R², 5-fold cross-validated accuracy and AUC, a ROC curve and a calibration plot.

Caveats worth discussing

  • Association is not causation. Class, sex, age and fare are tangled together (for example, fare is almost entirely determined by class), so adjusted and unadjusted results can differ.
  • The data describe a single event, so p-values here describe patterns within this group of people rather than a random sample from a wider population.
  • With thousands of observations, even small differences become statistically significant. Look at effect sizes (odds ratios, Cramér's V, Cohen's d) as well as p-values.
  • Lifeboat and body-recovery fields are consequences of the outcome, so they are left out of the regression to avoid leakage.

Using and hosting it

Everything lives in this single HTML file: the data, the statistics code and the charts. It makes no network requests and needs no server, so it works when opened directly or hosted on GitHub Pages.
